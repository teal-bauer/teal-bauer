## Projects

### 🛵 [Librescoot](https://github.com/librescoot)

Open-source firmware and services for the unu Scooter Pro. Go microservices, Flutter dashboard, Yocto Linux, CAN bus, NFC, the whole stack. I contribute across frontend, services, embedded, docs, and tooling.

### 📡 [reunu](https://github.com/reunu)

Community-driven documentation and tooling for the unu Scooter Pro. I contribute to the [technical reference](https://github.com/reunu/tech-reference) and the [unustasis](https://github.com/reunu/unustasis) mobile app.

### 🔬 [GhydraMCP](https://github.com/starsong-consulting/GhydraMCP)

Multi-instance Ghidra plugin with REST API and MCP bridge for AI-assisted reverse engineering, binary analysis, and decompilation. Includes a `ghydra` CLI tool to interact with Ghidra from the command line.
